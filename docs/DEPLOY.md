# Deploy — evolvo

## Vercel project
- Name: `evolvo`
- GitHub: https://github.com/ubaid-dev-01/evolvo

## CLI
```bash
cd evolvo
vercel --prod --yes
```

## Pipeline
1. Native Git: `vercel git connect https://github.com/ubaid-dev-01/evolvo.git`
2. GitHub Actions: set secrets `VERCEL_TOKEN`, `VERCEL_ORG_ID`, `VERCEL_PROJECT_ID`
